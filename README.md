# 🎯 계약서버개발실 D-DAY 상황판 (Mission Control Board)

계약서버개발실의 주요 마일스톤 및 TASK별 D-Day를 종합 상황판(Mission Control Board)처럼 한눈에 보여주는 웹 애플리케이션입니다.  
일반적인 D-Day와 달리 **워킹데이(주말 및 법정 공휴일 제외)**를 기준으로 남은 일수를 직관적으로 표시하며, 하단에 **하루 8시간 기준 남은 업무 시간(기준 시간 및 실시간 카운트다운)**을 정밀하게 제공합니다.  
한 화면에 최적화된 **6개 TASK 3×2 그리드 레이아웃**으로 대형 모니터나 상황실 TV 디스플레이에 적합합니다.

---

## 🌟 주요 핵심 기능

### 1. 직관적인 D-Day 상황판 (1화면 6개 TASK)
- **3×2 고대비 그리드 레이아웃**: 스크롤 없이 6개의 핵심 프로젝트 상황을 한눈에 조망.
- **초대형 히어로 D-Day**: 불필요한 부가 텍스트 없이 `D-3`, `D-8`, `D-DAY`를 시원시원한 대형 폰트로 즉각 인지.
- **워킹데이(영업일) 기반 D-Day 산출**: 토요일, 일요일 및 공휴일을 자동 제외한 정확한 D-Day 계산.
- **긴급도 시각화**:
  - `D-3 이내`: 레드 펄스(🚨 긴급 경고) 애니메이션
  - `D-7 이내`: 오렌지(집중 관리) 경고
  - `D-DAY`: 초록색 오픈 축하 하이라이트
- **목표 오픈일시 표기**: `🎯 오픈일자: YYYY.MM.DD (요일) HH:mm` 깔끔하게 노출.

### 2. 하루 8시간 기준 남은 업무시간 (하단 서브 영역)
- **기준 잔여 업무시간**: `남은 워킹데이 × 8시간` (예: 5일 남았을 때 `40시간 남음`)
- **실시간 잔여 카운트다운**:
  - 당일이 평일 근무시간(기본 09:00~18:00, 점심시간 제외)인 경우 오늘 남은 시간 + 이후 영업일 시간을 초 단위로 실시간 카운트다운 (`38시간 25분 12초`)
  - 매초 화면 갱신으로 생동감 있는 상황판 연출.

### 3. 강력한 Admin 관리 기능
- **TASK 등록 / 수정 / 삭제**:
  - 태스크명, 오픈 목표 일시(마감일), 시작일시
  - 카테고리 태그 및 커스텀 포인트 컬러
  - 중요도 (Critical, High, Medium, Normal)
  - 담당자 / 팀 및 주요 마일스톤 메모
- **슬롯 순서 변경 (Reorder)**:
  - 위/아래(▲/▼) 버튼으로 6개 표시 슬롯의 순서를 손쉽게 재배치.
- **빈 슬롯 자동 대응**:
  - 등록된 태스크가 6개 미만일 경우 빈 슬롯에 `+ TASK 등록` 카드가 자동 생성되어 클릭 한 번으로 추가 가능.

### 4. 공휴일 & 워킹데이 맞춤 관리
- **대한민국 법정 공휴일 자동 적용**: 2024년 ~ 2028년 신정, 설날, 추석, 대체공휴일 등 완벽 탑재.
- **사용자 정의 휴일 관리**: 회사 창립기념일, 전사 유급휴무일, 샌드위치 데이 등을 클릭하여 날짜와 명칭 등록/삭제 가능.
- **근무시간 커스텀**: 하루 기준 시간(기본 8시간), 출퇴근 시간(09:00~18:00), 점심시간(12:00~13:00) 설정 가능.

### 5. 멀티 스크린 실시간 동기화 (SSE) & 오프라인 지원
- **Server-Sent Events (SSE)**: Admin에서 태스크나 일정을 수정하면, 상황실 벽면 모니터에 떠 있는 화면이 새로고침 없이 즉시 실시간 동기화.
- **Zero-Dependency**: 외부 npm 패키지 설치 없이 Node.js 내장 모듈만으로 즉시 구동.
- **로컬 단독 실행 지원**: 서버 없이 브라우저로 `public/index.html`을 바로 열어도 로컬스토리지 기반으로 100% 정상 동작.

## 🚀 빠른 시작 방법

### 1) 서버 실행 (실시간 동기화 지원)
프로젝트 폴더에서 아래 명령어로 서버를 구동합니다:

```bash
cd /Users/ruroo/.gemini/antigravity/scratch/task-dday-board
npm start
# 또는 node server.js
```

브라우저에서 접속:
👉 **http://localhost:3000**

### 2) 서버 없이 브라우저로 바로 열기
Node 서버를 켜지 않고도 브라우저로 직접 파일을 열어 사용하실 수 있습니다:
- Chrome이나 Safari에서 `task-dday-board/public/index.html` 파일을 더블 클릭하여 실행.
